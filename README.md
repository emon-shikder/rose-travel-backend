# Rose Travel Backend

This is the backend for the Rose Travel application. It is built using Node.js and Express.

## Getting Started

To get started with the development server, run the following commands:

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the server (depending on your scripts, typically):
   ```bash
   npm start
   ```
   *Note: Update the start script in `package.json` if it hasn't been set up yet.*

## Tech Stack
- [Node.js](https://nodejs.org/)
- [Express](https://expressjs.com/)
